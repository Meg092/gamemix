# 硬币游戏 (Coin Flip Game)

## 功能描述

硬币游戏是一个简单的硬币翻转应用，用户可以通过点击"Start"按钮来随机翻转硬币，查看是正面（皇冠）还是反面（笑脸）。

## 主要功能

### 1. 硬币翻转
- 点击"Start"按钮开始硬币翻转
- 硬币会进行6次翻转动画，每次翻转100毫秒
- 最终随机显示正面（皇冠）或反面（笑脸）

### 2. 计数功能
- 自动统计正面（皇冠）和反面（笑脸）的出现次数
- 每次翻转后相应计数器会增加

### 3. 重置功能
- 点击"Reset"按钮可以重置所有计数器
- 重置后正面和反面计数都归零

### 4. 动画效果
- 硬币翻转时有3D旋转动画效果
- 翻转过程中硬币图标会交替显示
- 按钮在翻转过程中会显示"翻转中..."状态

## 界面元素

### 顶部
- 标题："硬币游戏"

### 中间区域
- 两个大硬币图形（皇冠和笑脸）
- 硬币计数器显示当前统计

### 底部
- Start按钮：开始硬币翻转
- Reset按钮：重置计数器

## 技术实现

- 使用GetX进行状态管理
- 响应式UI设计，支持不同屏幕尺寸
- 流畅的动画效果
- 随机数生成确保公平性

## 使用说明

1. 打开应用，进入硬币游戏页面
2. 点击"Start"按钮开始翻转硬币
3. 观察硬币翻转动画和最终结果
4. 查看计数器了解历史统计
5. 需要重置时点击"Reset"按钮
